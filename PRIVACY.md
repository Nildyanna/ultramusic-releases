# Privacy Policy

**Applies to:** the personal tool "Plex YouTube Music Sync" and the UltraMusic software published from this repository, written and used by the repository owner (GitHub: Nildyanna).

## Who uses it
The tool is for personal use by its owner. It is not offered as a service, and there is no sign-up, account system or server run by the developer.

## What it accesses
When the owner signs in with Google, the tool can read and edit the owner's own YouTube Music playlists. It uses that access only to create and update playlists that mirror a playlist on the owner's own Plex media server. It does not read other Google data, and it does not touch likes or the rest of the library.

## What is stored, and where
The sign-in token, the owner's Plex details and a cache of track matches are stored only as files on the owner's own computer. Nothing is uploaded to, stored on or shared with the developer or any third party. The only services contacted are Google/YouTube (to read and update the owner's playlists) and the owner's own Plex server.

## Sharing and selling
No data is sold, shared, or used for advertising. No data is transferred to anyone else.

## Deleting access
The owner can revoke the tool's access at any time at https://myaccount.google.com/permissions and can delete the stored files from their computer.

## Contact
Questions: open an issue on this repository.
